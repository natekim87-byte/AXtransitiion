# 리테일 AX 플레이북

B2B·B2C 리테일 기업의 AX(AI Transformation) 실무자를 위한 6단계 실행 가이드입니다.

1. 회사의 AI 수준 진단 (25문항 자가진단)
2. 성숙도에 따른 프로세스 적용 레벨 산정
3. 우선 적용 업무 선정 (부서별 후보 업무, 스코어카드)
4. AI 적용 방법론과 실행 방식 (AWS CAF for AI 기반)
5. 실행 계획 수립 (과제 카드, KPI, 일정, Tableau + MCP + LLM 적용 예시)
6. ROI 계산기

- 웹사이트 (한국어): https://axtransitiion.vercel.app
- Website (English): https://axtransitiion.vercel.app/en/ · 브라우저 언어가 한국어가 아니면 자동으로 영어 버전으로 이동하고, 우상단 언어 선택은 브라우저에 기억됩니다.
- 문서 버전: [AX_가이드북_리테일.md](AX_가이드북_리테일.md) (웹사이트와 같은 내용을 Markdown으로 정리, 노션 가져오기 가능)
