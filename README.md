# 리테일 AX 플레이북

B2B·B2C 리테일 기업의 AX(AI Transformation) 실무자를 위한 6단계 실행 가이드입니다.

1. 회사의 AI 수준 진단 (25문항 자가진단)
2. 성숙도에 따른 프로세스 적용 레벨 산정
3. 우선 적용 업무 선정 (부서별 후보 업무, 스코어카드)
4. AI 적용 방법론과 실행 방식 (AWS CAF for AI 기반)
5. 실행 계획 수립 (과제 카드, KPI, 일정, Tableau + MCP + LLM 적용 예시)
6. ROI 계산기
